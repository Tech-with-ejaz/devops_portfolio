---Repository
    A Repository is a physical area that holds soft copy of project source code, doumentation, configuration files and is managed by GIT.
    It has following types:
    i)    Local repository     A repository that is at local machine is called Local repository. 
    ii)  Remote repository    A repositoy that is at web plate form say GitHUb, AWS, Azur, GCP, is called Remote repository.

---Working Directory
    Working Directory is a primary dirrectory where DevOps Engineers Prepare Project Directories, Configuration Files,Deployment files, IaC Files, Test Files, Edition, Delition or Improvement.
    It contains all files that Run, Test, Deploy MOnitor the Project Source Code, and its relevent files are then Add to Local Repo, then Stagged, and then Pushed to Remote Repository.

--- Stagging Area
    It is an area which prepared the snapshot of a project .
    Git Add . is a Git command that adds the project's all files from local directory  in local repository.
     Gitcommit -m (commit to store in staggin area)  is a Git command that stores the snap shot of local repository in Staggin Area of local Repository.

--- Branch
    Branch is a section of workflows that contains the project files for Run,Test, Deploy , Monitor , Cashe which then result  in artifact.
    Branches can be one or more, Branch Main is the final branch that has final cashe or artifact to execute the project.
